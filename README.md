# Olá, eu sou o Fábio Daniel Godoy Quaiati 👋

**Professor de Tecnologia | Desenvolvedor Web Full Stack**

Sou professor de ensino técnico modular e no ensino MTEC-PI no Centro Paula Souza (Etec), onde leciono, desenvolvimento WEB I,II,III, banco de dados I, II. Minha paixão é transformar a educação tecnológica, unindo código, arquitetura de sistemas e projetos multidisciplinares que engajam os alunos na prática.

Além da sala de aula, atuo fortemente como mentor de equipes estudantis em competições de tecnologia e empreendedorismo, sempre buscando conectar o aprendizado técnico com desafios do mundo real.
